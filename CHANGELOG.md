# Changelog

## 2.5.0 — 2026-09-09

- First store-preparation release of the current AppTower implementation.
- Grouped site settings and Edge-inspired appearance controls.
- Added settings search, safe visual/performance reset, About and feedback link.
- Added transparent extension icons and Fluent icons for broom and eyedropper.
- Removed the extension new-tab override; onboarding opens only after first
  installation.

The previous implementation and its release history are preserved in the
`legacy/v1` branch.
