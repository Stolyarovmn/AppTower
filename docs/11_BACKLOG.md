- BookmarkFlow's restore is additive: it creates a dated folder and recreates bookmark nodes rather than deleting existing bookmarks. However, it writes backed-up folder-color, tag and pinned-folder maps before recreation while those maps are keyed by the original browser bookmark IDs; recreated nodes receive new IDs and no old→new remap is built. AppTower's portable format must use stable exported identities or deterministically remap every reference, stage and validate before commit, preserve the original state on failure, and test duplicate/import/reimport/cross-profile cases.

AppTower copies no implementation; any bookmark bridge requests `bookmarks` only when enabled and adds no global content script.
