Основные

App Tower

Горячая клавиша поиска по умолчанию: Ctrl+Shift+Space.

Оформление

Workspaces

Ярлыки

Здесь не только список: ярлыки можно открыть, отправить в нижнюю pane, настроить группу/шаблон или удалить. Перетаскивание и точный порядок остаются в rail.

Недавние

Последние сайты и шаблоны App Tower. В настройках показываются записи по всем workspace; поиск внутри панели сначала поднимает текущий workspace.

Сайты

Per-site настройки применяются по origin ко всем ярлыкам этого сайта.

Уведомления

Для обычных сайтов можно выбрать по умолчанию / разрешить / блокировать. Это браузерная настройка origin и действует не только внутри App Tower. Выбор типов уведомлений возможен только для модулей, которые сами объявляют категории.

Производительность

«Не усыплять» защищает сайт от таймера 5 минут, но жёсткий глобальный лимит всё равно имеет приоритет: больше выбранного количества живых web/media pane App Tower не держит.

Диагностика загруженных pane

Это не лог. Здесь показаны iframe/media-поверхности, которые прямо сейчас считаются загруженными и участвуют в лимите.

Модули

Web Apps

Это сайты со стандартным Web App Manifest. Для каждого можно открыть обычную pane, запустить отдельное top-level приложение (sidecar), выбрать App-режим для Auto или забыть обнаруженную запись.

Sidecar Manager

Sidecar — отдельное top-level окно, которое App Tower создаёт для Real Page или Web App. Обычная native Side Panel справа не является sidecar. Здесь появятся только реально открытые отдельные окна.

Media

Core содержит единый media-contract. Управление play/pause появится только у модулей с проверенным transport API; iframe без такого API не эмулируется.
