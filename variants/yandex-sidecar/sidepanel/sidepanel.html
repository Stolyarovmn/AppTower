App Tower v1.0.0

Оформление

App Tower Auto

Системная тема реагирует на светлый/тёмный режим ОС. Системный акцент используется, если браузер отдаёт CSS AccentColor; иначе применяется стандартный цвет App Tower.

Данные

Модули

Auto-адаптеры устанавливаются отдельно. Ядро исполняет только фиксированный декларативный формат — модуль не может подгрузить JavaScript.

Веб-приложения

App Tower распознаёт стандартный Web App Manifest. Для выбранных приложений Auto может не использовать iframe, а показывать запуск top-level sidecar-окна.

Раскладка

Режимы отображения
AAuto: специальный renderer, если он есть; обычный сайт автоматически использует совместимость.
SSecure: сайт открывается без изменения защитных заголовков.
CCompatibility: X-Frame-Options и CSP удаляются только для доменов этой области.
RReal Page: настоящая browser page в отдельном окне/вкладке.
