# Historical archive

This directory is intentionally separate from the active source.

- `releases/edge-chrome/` — every available historical Edge/Chrome full ZIP
- `releases/yandex-sidecar/` — historical fallback ZIPs
- `RELEASE_INDEX.csv` — version/platform/size/SHA-256
- `CHECKSUMS.sha256` — hashes for the archived ZIPs
- `release-notes/RELEASE_NOTES_ARCHIVE.md` — combined historical README text
- `release-notes/individual/` — README snapshots per version when present
- `latest-runtime-issue-v0.8.4.png` — one preserved runtime screenshot that led
  to the v0.8.5 current-page/collapse recovery pass

Historical source packages are immutable evidence. Do not edit ZIP contents in
place. Add a new version instead.
