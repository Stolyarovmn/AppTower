# Store reviewer instructions

1. Install the package and open any HTTP(S) tab.
2. Click the AppTower toolbar icon to open the Side Panel.
3. Click **Add current page** to create a shortcut.
4. Open the shortcut, then use the layout control to create the second pane.
5. Add another page to the lower pane and confirm that the upper pane remains
   open.
6. Open **Settings** from the compact rail or panel to review appearance and
   per-site settings.

No account, credential or payment is required for review. A site that blocks
iframe embedding can be opened as a normal tab or in a separate window.
