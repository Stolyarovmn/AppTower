# Support

## Bugs and feature requests

Use the GitHub issue templates for reproducible bugs and feature requests.

For bugs, include:

- App Tower version;
- browser and browser version;
- exact reproduction steps;
- expected and actual behavior;
- screenshots/logs where safe;
- whether the issue happens after browser restart or extension Reload.

Known limitations and the current verification queue are tracked in `docs/10_KNOWN_ISSUES.md`.

## Security issues

Do not report security vulnerabilities in a public issue. Follow `SECURITY.md`.

## Store/privacy questions

For privacy, data-handling or store-submission questions, see `PRIVACY.md` and `docs/21_STORE_SUBMISSION.md`.
